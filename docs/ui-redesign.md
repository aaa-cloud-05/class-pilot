# UI リデザイン — 作業メモ（モック段階）

最終更新: 2026-09-16

**状態：モックで検討中。** 本番の画面はまだ変えていない。
モックは `/mock` にある（本番環境では 404。ローカルと Vercel のプレビューでだけ見られる）。
確定したら、この文書をもとにルートの `DESIGN.md` を書き起こし、本番の UI を置き換える。

## 進め方

1. `/mock` にダミーデータで動く画面を作る（API・DB には一切触れない）
2. ユーザーが実機（スマホ・PC）で触り、配色やレイアウトを直す → 繰り返す
   - よく変える項目は、画面右端の「調整」パネルでその場で切り替えられるようにしてある
3. 確定したら `DESIGN.md` を書き、トークンと部品を本番に移し、画面ごとに PR で置き換える
4. 置き換えが終わったら `src/app/mock/` と `globals.css` の `@import "./mock/ui-tokens.css"` を消す

## 決定事項（2026-09-16）

- OG 画像は別の AI が作ったもので、**UI の参考にしない**
- メインカラーは **#2F6BFF 系の鮮やかな青**、または **Vercel 風の白黒灰**。モックで両方を比べる
- **ダークモードを設定から選べる**ようにする（自動 / ライト / ダーク）
- **モバイル優先で、PC 用のレイアウトも作る**
- タブ構成は任せる。ただし**今ある機能を1つも減らさない**（下の対応表で確認する）

## スキルの使い分け

| 場面 | 使うもの | 理由 |
|---|---|---|
| 配色・書体の候補出し、UX ルールの確認（タップ領域・ナビ・フォーム・ダーク時のコントラスト） | **ui-ux-pro-max** | 製品 UI 向けのルール集と検索がある。アプリ画面の良し悪しを判定する物差し |
| 既存画面の「AI っぽさ」監査、仕上げ前のチェック | **tasteskill: redesign-existing-projects** | 既存コードを 監査 → 診断 → 修正 の順に進める手順になっている |
| モノクロ方向の味付け | **tasteskill: minimalist-ui** | 白黒＋細線＋余白の作法 |
| 公開向けのページ（ログイン画面・将来のトップページ） | **tasteskill: design-taste-frontend** | LP・マーケ面が本来の守備範囲。アプリの一覧画面には向かない（本人がスコープ外と明記） |
| 全画面の最終チェック | 両方 | tasteskill の「AI っぽい表現の禁止リスト」＋ ui-ux-pro-max の Pre-Delivery Checklist |

tasteskill から採用するルール（アプリ画面にも効くもの）: アクセント色は1つだけ固定・角丸の体系を1つに固定・
ボタンの文字と背景のコントラスト確認・装飾だけの色付きドットを使わない（状態を表す点は可）・
意味のないアニメーションを入れない・`prefers-reduced-motion` 対応・ライト/ダーク両方を最初から作る。
採用しないルール: lucide 禁止（プロジェクトが既に依存しているので継続）、ランディング用のヒーロー/ベント規則。

## 画面構成（新）

### モバイル（〜1023px）

下部ナビは **3タブ＋追加ボタン**。ラベル付き。サブページでもナビを消さない。戻るは左上。

| タブ | 役割 | 主な中身 |
|---|---|---|
| **ホーム** | 「いま何をやるか」 | 件数サマリ（期限切れ・今日・今週）／はじめの設定カード（未完了時のみ）／未提出の課題を締切でグループ化したリスト（期限切れ・今日・明日・今週・来週・それ以降・期限なし）／表示切替（未提出のみ・すべて）と並び順（締切順・状態順） |
| **カレンダー** | 「いつ何があるか」 | 週・月の切替、選んだ日の課題、期間の提出進捗 |
| **設定** | 変えるもの全部 | アカウント／連携（Classroom・WebClass）／通知／コース／表示（テーマ）／ヘルプ／このアプリについて／危険な操作 |
| ＋ボタン | 課題を追加 | 下から出るシート |

ヘッダー右（ホーム）: **同期ボタン**（2つの取得元の状態をまとめて表示 → タップで同期シート）と**通知ベル**（未読バッジ → 通知ページ）。

### PC（1024px〜）

- 左に**サイドバー**（ロゴ・課題を追加・ホーム / カレンダー / 通知 / 設定・同期状態・アカウント）
- ホーム: 左に課題リスト、右に「概要（進捗・ミニカレンダー・はじめの設定）」。課題を選ぶと右側が詳細に切り替わる
- カレンダー: 大きな月表示（課題名まで見える）＋右に選んだ日の課題
- 設定: 左に項目一覧、右に内容の2ペイン

## トークン（モックの初期値）

`src/app/mock/ui-tokens.css` が正本。値はモックで調整する。

- 色: `canvas`（地）/ `surface`（カード）/ `surface-2`（押下・入れ子）/ `line` / `ink`・`ink-2`・`ink-3`（文字3段階）/
  `brand`（主ボタン）/ `brand-text`（リンク・選択中の文字）/ `brand-soft` / `signal`（今日・フォーカス）/
  状態色 `danger`（期限切れ）・`warn`（今日・24時間以内）・`ok`（提出済）
- 「青」方向: `brand` = #2F6BFF。「モノクロ」方向: `brand` = インク色、`signal` だけ青
- 角丸: 操作部品 12px / カード 16px / シート 24px / チップ・切替・丸ボタンは完全な丸
- 文字: 本文 16px・補足 14px・注記 13px・最小 12px。見出し 17 / 22 / 28px。行間は本文 1.6
- 書体: 欧文・数字は Plus Jakarta Sans、和文は切替で比較（システム / Noto Sans JP / LINE Seed JP / IBM Plex Sans JP）
- タップ領域: 44px 以上。リストの行は高さ 64px 前後
