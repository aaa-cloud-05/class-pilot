## コア機能の抜け（基本／公開に必要）
- [ ] 🔴 **アカウント/データの自己削除**：`DELETE /api/account` 等で当該ユーザーの Assignment/NotificationSetting/NotificationHistory/Account を削除＋ローカル消去。ポリシーは「連絡して削除」止まり。

- [ ] 🟡 データエクスポート手段が無い（開示請求対応）。

## セキュリティ
- [ ] 🟠 **レートリミット皆無**（middleware 無し）。`/api/classroom/sync`（Google 1+2N回）・`/api/import/webclass`（一括書込）が連打可能。per-user スロットルを。
- [ ] 🟠 **入力バリデーション無し**：各ルートが `request.json()` を無検証で信頼。`/api/import/webclass` は巨大配列を受け得る（サイズ/件数上限なし＝DoS余地）。zod等＋上限を。
- [ ] 🟡 **メールHTMLへ未エスケープ埋め込み**（`src/lib/server/email.ts` の `${assignmentTitle}` 等）。今は自分宛のみで低リスクだが「クラス内シェア」実装前にエスケープ必須。
- [ ] 🟡 `Account.refresh_token` 保存（cronはDB化で未使用に）。DB侵害＝全ユーザーのClassroom読み取り。不要なら保存廃止検討。
- [ ] 🟡 `CRON_SECRET` 比較が非定数時間（軽微）。ブックマークレットが課題データをURLハッシュで渡す→履歴に残る（軽微）。
