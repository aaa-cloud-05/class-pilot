- [x] 🟠 **成績の非保持**：Classroom の `assignedGrade`/`maxPoints`、WebClass の最高点はいずれも**取得も保存もしていない**（`transform.ts` / `webclass.ts` で除外）。プライバシーポリシーの記載と実装が一致していることを確認済み。
  - 残：`Assignment` テーブルに未使用の `grade` / `maxPoints` カラムだけが残っている。混乱の元なので、いずれ削除してよい。

- [ ] 🟠 WebClass 規程の「定められた目的以外の利用」が唯一のやわらかい論点。CSV取込の方が更に安全。多数配布前に情報基盤へ一報が無難。

## コア機能
- [x] 🔴 **アカウント/データの自己削除**：`DELETE /api/account`（User 1行削除で全リレーションが Cascade）＋ 設定画面に確認入力つき UI。ローカルミラーの消去とサインアウトも実施。
- [x] 🟡 **ワンタップ「提出済みにする」**：カードのランプをタップして楽観更新。
- [x] 🔴 **メール通知の取りこぼし**（2026-09-04）：cron が1日1回のため、予約時刻を過ぎたタイミングが全て捨てられ、`relaxed` プリセットや「cron 後に取り込んだ当日締切の課題」が無通知になっていた。予約できるタイミングが無い場合に限り、締切に最も近い1件を実際の残り時間ラベルで即時送信するよう変更。あわせて同期・取り込みの成功時にも通知を確定させる（`after()` でレスポンスは待たせない）。二重送信は履歴行の事前予約で防止。
- [ ] 🔴 **未ログイン時の編集/削除が不可**：`src/app/page.tsx` は `onEdit/onDelete` を loggedIn 時のみ渡す。未ログイン(IndexedDB専用)は追加のみ。
- [ ] 🟡 予約メールが提出後/締切変更後もキャンセルされない（Resend のメールIDを履歴に保持して `emails.cancel`）。
- [ ] 🟡 クライアント通知のラベルが定義値（「24時間」）固定。サーバー同様、実際の残り時間に合わせる。
- [ ] 🟡 ソフトデリート(`deletedAt`)が無期限蓄積。定期 purge 未実装。
- [ ] 🟡 データエクスポート手段が無い（開示請求対応）。
