# 動画（2本）

最終更新: 2026-09-30 ／ ステータス: **2本とも作った**（`video/` の `teaser` と `guide`）。書き出しと手順は [video/README.md](../video/README.md)。

どちらも `video/`（Remotion）で組む。アプリの画面は**本物の UI** をデモデータで撮り（`scripts/demo-seed.mjs`）、カメラで寄って、カーソル（スマホは指の丸）・押した波紋・囲み枠で見る場所を示す。
**他社のロゴ（Google Classroom・WebClass）は使わない**。実在の氏名・学籍番号・大学名・コース名は映さず、スケルトン（灰色の棒）にする。
BGM と効果音は `video/scripts/make-audio.mjs` で合成したもの（素材のライセンスを気にしなくてよい）。X は無音で再生されるので、言いたいことは文字に全部書く。

## A. 紹介動画（X に貼る用）

| 項目 | 内容 |
|---|---|
| 目的 | タイムラインで手を止めてもらい、unionfetch.com を開いてもらう |
| 見る人 | 同じ大学で WebClass と Classroom の両方を使っている学生 |
| 長さ | 約32秒、30fps（カレンダーとメールは、動きのあと少し止めて見せる） |
| 画面 | **1080×1080（1:1）が本命**（`npm run teaser`）。同じ構成で 1920×1080（`npm run teaser:wide`） |
| 音 | BGM と効果音（無音でも伝わる作り） |

### 構成（2026-09-30 の版）

| 秒 | 画面 | 文字 |
|---|---|---|
| 0–5 | 困りごとのカードが3枚、1枚ずつ出る（1枚目は最初から出ていて、X のサムネイルに入る） | 「課題の締切、こんなことない？」①WebClass と Classroom に分かれていて管理しにくい ②締切が近づいても通知が来ない ③気づいたら過ぎていた |
| 5–10 | WebClass と Google Classroom の窓（中身はスケルトン）に課題が散らばり、札（WebClass / Classroom）を付けたまま締切順の1列に集まる | ロゴ＋「UnionFetch なら、WebClass と Classroom を、まとめて取り込み。」→「課題の締切を、ひとつの場所で。」 |
| 10–13 | 本物のホームをリストまでスクロール。行の外に札を出す（WebClass は左、Classroom は右） | 「WebClass も Classroom も、締切順に並ぶ。」 |
| 13–18 | 今週のカードに寄り、いちばん多い木曜の棒を囲む → 押すとその日の課題が並ぶ（押したあとの画面も本物） | 「今週の忙しさが、ひと目で。」「棒を押すと、その日の課題が並ぶ」 |
| 18–21 | 本物の月のカレンダー。日付を押すと、その日の課題 | 「1か月の締切も、カレンダーで。」 |
| 21–24 | 通知のカードが降りてきて、押すと本物のメール本文 | 「締切の前に、メールでお知らせ。」「通知のない WebClass の課題にも」 |
| 24–27 | 本物のログイン画面で「Google でログイン」を押す → 課題の並んだホーム | 「Google でログインするだけ。」「Classroom の課題が、すぐに並びます」 |
| 27–29 | ロゴ・URL | 「unionfetch.com」小さく「WebClass も、かんたんな設定で取り込めます」 |

- 「ログインしなくても試せる」は言わない（呼びかけは「Google でログイン」の1つに絞る）
- WebClass の設定の手順は言わない。ただ「ログインすれば WebClass も入る」と誤解されないよう、最後に1行だけ書く

### 投稿文の案

> WebClass と Google Classroom の課題を、締切順にひとつのリストへ。
> 締切の前にメールでお知らせします（通知のない WebClass の課題にも）。
> Google でログインするだけで始められます → unionfetch.com

## B. 使い方（Classroom と WebClass のつなぎ方）

| 項目 | 内容 |
|---|---|
| 目的 | つなぎ方で止まる人をなくす。問い合わせの前に見てもらう |
| 置き場所 | **アプリに埋め込み**（設定 › セットアップのいちばん上。`public/videos/guide.mp4`・約6MB、再生を押したときだけ読み込む）。書き出しは `cd video && npm run guide:web` |
| 長さ | 約1分35秒（`npm run guide`・1920×1080） |
| 並べ方 | 左に「いま何をするか」（手順の番号・短い説明・ヒント）、右に画面 |
| 音 | 落ち着いた BGM と、押したときの音 |

### 構成（2026-09-30 の版）

Classroom と WebClass の区切りが分かるよう、章の頭に扉を入れる。扉には「はじめにやること」と「2回目からやること」を並べる
（Classroom は2回目からは何もしない、WebClass は2回目からブックマークを押す）。

| 章 | 見せるもの |
|---|---|
| はじめ | 「はじめ方」。やることは2つ（① Google でログイン → Classroom ② ブックマークを1つ登録 → WebClass） |
| 扉 1. Classroom をつなぐ | はじめ: Google でログインするだけ ／ 2回目から: 何もしなくて大丈夫（開くたびに自動で更新） |
| Classroom（PC） | ホーム →「セットアップを開く」→「Google でログイン」→ Google の許可（簡単に描いたもの。アカウントはスケルトン）→「すべて選択」→「次へ」→ ホームに課題が入る（入る様子は作りもの）。「2回目からは何もしなくて大丈夫」「スマホも同じ手順」 |
| 扉 2. WebClass をつなぐ | はじめの1回: ブックマークを1つ登録する ／ 2回目から: WebClass で、そのブックマークを押すだけ |
| WebClass・はじめの1回（PC の Chrome） | コードをコピー → ☆ でブックマーク（Ctrl + D でも）→ ヒント「ブックマークバーは Ctrl + Shift + B で表示」→ 右クリック「編集...」→ URL を全部消して Ctrl + V → 保存（名前は変えない） |
| WebClass・はじめの1回（iPhone の Safari） | コードをコピー →「…」→「ブックマークに追加」→「…」→「ブックマーク」→「編集」→ 追加した項目 → URL を ✕ で消して長押し →「ペースト」→ 保存（名前は変えない）。ヒント「Android（Chrome）も同じ流れ」 |
| WebClass・2回目から | PC: WebClass（スケルトン）でブックマークを押す → 取り込み中 → 取り込みました（本物）→ ホーム。スマホ:「…」→「ブックマーク」→ 押す → 同じ流れ。「締切が変わったら、もう一度押せば更新」 |
| まとめ | Classroom: ログインすれば、あとは自動 ／ WebClass: 開いてブックマークを押す。メール通知は 設定 › 通知、困ったら 設定 › ヘルプ、unionfetch.com |

- 左の説明の補足（灰色の文）は大事なことを書いているので、灰色の中では濃く・太めにしてある

- 参考にしたのはユーザーの画面録画（PC の Chrome・iPhone の Safari、2026-09-30）。**録画そのものは使わない・リポジトリに入れない**（名前・メールアドレス・大学の画面が映っているため）。
  ブラウザ（Chrome・Safari）・Google の許可画面・WebClass は、録画を見て形を合わせ、Remotion で描き直した（`video/src/guide/ui/`）
- アプリの画面は本物（`scripts/guide-shots.mjs`）。取り込み中の画面だけは一瞬で終わって撮れないので、同じ見た目で描いている
- 入れていないもの: PC の自動取り込み（Tampermonkey）、ホームやカレンダーの見かた、メール通知の設定の中身。必要になったら章を足す
